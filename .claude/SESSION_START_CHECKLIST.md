# Claude Session Start Checklist

**Auto-read these files at session start** (in order):

## 1. RULES.md
- Documentation rules
- Where to put new docs
- Prevents .md sprawl

## 2. PROJECT_CONTEXT.md
- What the project is
- Current state
- Key files
- Architecture patterns

## 3. FIXES_APPLIED.md
- What's been fixed (with line numbers)
- Patterns to follow

## 4. CODE_PATTERNS.md
- How to code correctly
- Examples of right/wrong patterns

---

## Session Start Actions

1. ✅ Read above 4 files
2. ✅ Check CHANGELOG.md for recent work
3. ✅ Understand: Only 2 .md files belong in root
4. ✅ Understand: New docs go in .archive/sessions/

## Session End Actions

1. ✅ Update CHANGELOG.md with summary (top of file)
2. ✅ Add to FIXES_APPLIED.md if fixes applied (append one line)
3. ✅ Create .archive/sessions/DATE-topic.md for detailed work
4. ✅ NEVER leave .md files in root (except README/CHANGELOG)

---
